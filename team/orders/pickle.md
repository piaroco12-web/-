발령: Claude Code(총괄) · 브랜치: `pickle/<작업명>` · 작업기록: 방문 폴더의 `pickle-worklog.md`
먼저 읽을 것: [`/AGENTS.md`](../../AGENTS.md), [`team/README.md`](../README.md)

방문 폴더 = `reports/2026-11-19_인천송도_채드윅국제학교-제물포AI센터/` (이하 `V/`)

## 임무 1 — 전사본 양식 `V/transcripts/_양식.md` (지금, 단계 0)
아래 양식을 파일로 만들어 둔다. 모든 전사본은 이 구조를 따른다.

```markdown
# [세션 제목]
| 항목 | 내용 |
|---|---|
| 일시 | 11/19 HH:MM~HH:MM |
| 장소 | 채드윅 송도국제학교 ○○실 |
| 발표자 | 이름(직책) — 모르면 "발표자1" |
| 원본 | inbox/파일명 |
| 관련 사진 | P03, P04 (Codex INDEX.md 번호) |

## 1. 세션 요약 (5줄 이내, 개조식)
## 2. 주요 내용 (주제별로 묶음, 각 줄 끝에 [MM:SS])
## 3. 질의응답 (Q/A 형식, [MM:SS])
## 4. 인용 후보 (보고서에 그대로 쓸 만한 문장 3~5개, 원문 그대로 + [MM:SS])
## 5. 불명확 구간 (잘 안 들린 곳, 고유명사 확인 필요한 곳)
```

## 임무 2 — 전사본 정리 (단계 2: 1일 차 / 단계 4: 2일 차)
- 입력: `V/inbox/`의 텍스트 전사본(휴대폰 녹음 앱·클로바노트 결과)
- 출력: `V/transcripts/HHMM_발표자_주제.md` (HHMM은 세션 시작 시각)
- 정리 원칙
  - 말버릇("어", "그러니까")·반복은 지우되 **의미는 바꾸지 않는다**
  - 영어 발표는 원문 핵심 문장 + 한국어 번역을 같이 적는다
  - 자동 전사가 틀린 것으로 보이는 고유명사(학교명, 프로그램명, 도구명)는 고치지 말고 `[확인 필요: 원문 "○○"]`로 표시
  - 학생 이름이 나오면 `학생A`처럼 익명 처리
- 세션 하나 끝낼 때마다 커밋하고 작업기록에 적는다

## 임무 3 — 인용 대조 (단계 5)
- Claude가 `report.md`에 인용한 문장이 전사본 원문과 맞는지 하나씩 확인
- 틀린 것은 작업기록 `요청` 칸에 "report.md 3-1 두 번째 인용 — 원문은 ○○" 형식으로 적는다 (report.md 직접 수정 금지)
