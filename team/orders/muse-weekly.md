# 작업 명령서 — 뮤즈 (Muse) · 주간 노션 정리 · 매주 토요일

발령: Claude Code(총괄) · 마감 **매주 토요일 07:00 (KST)** · 반복 업무

## 상황
선생님(충남소프트웨어교육체험센터 파견교사, 2027 교육전문직 준비 중)이 매주 토요일 09:00에 **주간 AI 활용 분석 보고서(docx)** 를 받음.
Claude가 07:47부터 기록을 모아 분석함. 뮤즈는 그 전에 **노션에 남은 한 주 기록**을 정리해 넘겨 줘.

## 정리 범위
- 기간: **지난주 토요일 00:00 ~ 이번 주 금요일 24:00 (KST)**
- 대상: 기간 안에 새로 만들었거나 수정한 노션 페이지·데이터베이스 항목 전부
- 선생님이 노션에 남긴 **Claude 대화(claude.ai) 메모**도 포함 — Claude는 이 대화 기록을 직접 볼 수 없으므로 뮤즈 정리본이 유일한 출처임

## 만들 것 — `notion.md` 한 파일
아래 4개 영역으로 나눠 정리. 각 항목은 `- [날짜] 제목 — 한 줄 요약 (페이지 제목 또는 링크)` 형식.

````
# 노션 주간 정리 — YYYY-Www (MM/DD~MM/DD)

## 1. AI·코딩 기술 역량
## 2. 2027 교육전문직 준비   ← 공부한 주제, 기출·예상문제, 충남교육 정책 메모
## 3. SW교육체험센터 업무    ← 수업·프로그램·보고서·행사
## 4. AI 활용 방식           ← 어떤 AI를 무엇에 썼는지, 잘된 점·막힌 점

## 이번 주 Claude 대화 요약
- [날짜] 주제 — 무엇을 물었고 무엇을 얻었는지 한 줄

## 선생님이 직접 남긴 고민·목표 (있으면 원문 그대로 짧게 인용)

## 수집 현황
- 확인한 페이지 수: N개 / 영역 분류가 애매한 항목: N개 (어느 영역 후보인지 적기)
- 제외한 생활 비서 항목: N건 (내용은 적지 않음)

(맨 끝에 아래 집계표 — Codex 통계용. 열은 탭으로 구분, 원본은 노션 행 URL)
```notion-tsv
날짜	도구	유형	원본
2026-11-16	피클	작업	https://app.notion.com/…
```
````
(기록이 0건이면 머리행만 남김. 도구 칸: Claude·Codex·피클·뮤즈·부이·큐 중 하나, 모르면 `미상`. 유형: `작업` 또는 `요청`)

## 규칙
1. **요약만, 해석·조언은 쓰지 않음** — 진단과 조언은 Claude가 함. 뮤즈는 "무엇을 했는지"만.
2. **지어내지 말 것** — 노션에 없는 내용은 쓰지 않음. 불확실하면 `[확인 필요]`.
3. **개인정보 제외** — 학생 실명, 연락처, 개인 신상은 빼거나 익명 처리(예: 학생A).
4. 한 항목이 여러 영역에 걸치면 **가장 가까운 영역 하나**에만 넣고 끝에 `(+영역2)` 표시.
5. 기록이 없는 영역은 비우지 말고 `- 이번 주 기록 없음`이라고 적음.
6. 분량: 전체 80줄 이내.
7. **기간 엄수** — 제목의 기간은 `지난주 토(MM/DD)~이번 주 금(MM/DD)`. 토요일 당일(제출일) 기록은 다음 주로 넘김.
8. **생활 비서 항목 제외** — 카드·결제·영수증·금액, 주소·정부24, 메일 정리, 아바타 등 개인 생활 업무는 본문과 집계표 모두에서 빼고 `수집 현황`에 건수만 적음.
9. **AI 표시** — 모든 항목 앞에 `[도구명]`을 붙임. 노션 로그에 도구가 비어 있으면 `[미상]`.

## 제출 위치 (둘 중 가능한 방법으로)
- **1순위 — GitHub:** 저장소 `piaroco12-web/-`, 브랜치 `muse/weekly-notion`에
  `weekly/logs/YYYY-Www/notion.md` (ISO 주차, 예: `2026-W48`)로 커밋. Claude 브랜치에는 푸시하지 않음.
- **2순위 — GitHub 접근이 안 될 때:** 노션에 `주간 정리 YYYY-Www` 페이지로 만들고, 같은 내용을 텍스트로 선생님께 전달.
