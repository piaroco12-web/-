## 3. 자료 흐름

```
선생님 ──(사진·전사 텍스트·메모)──▶ 아무 AI에게 전달
                                      │ 받은 AI는 손대지 않고 inbox/에 그대로 커밋
                                      ▼
            inbox/ ──▶ 사진: Codex → photos/      전사: Claude → transcripts/
                                      │
            피클: research/국내_*   부이: research/해외_*   (현장 자료와 병행)
                                      ▼
            Claude: report.md 초안 → 검수 → 최종본 → Codex: export/ 변환
```

`inbox/` 파일명: `MMDD_HHMM_원래이름` (예: `1119_1405_녹음1.txt`). 시각을 모르면 `MMDD_원래이름`.

## 5. 브랜치와 인계

- 브랜치: Claude `ccr-e265f827-drcdyq` · Codex `codex/<작업명>` · 피클 `pickle/<작업명>` · 부이 `vooy/<작업명>`
- **작업 시작 전 반드시** Claude 브랜치를 받아 와서 그 위에서 작업한다: `git fetch origin && git merge origin/ccr-e265f827-drcdyq`
- 저장소에 직접 올릴 수 없는 AI는 결과물을 마크다운 텍스트로 선생님께 주고, 선생님이 Claude에게 전달한다. Claude가 해당 파일 경로에 대신 올리고 출처를 `(작성: 피클)`처럼 남긴다.
- 작업이 끝나면 작업기록에 `완료 / 다음 / 요청`을 적는다. Claude가 확인해 합친다.
- 전체 진행 상황은 방문 폴더의 [`STATUS.md`](../reports/2026-11-19_인천송도_채드윅국제학교-제물포AI센터/STATUS.md)에서 Claude가 관리한다.

## 6. 작업기록 양식 (`<이름>-worklog.md`)

```markdown
## 11/19 HH:MM
- 완료: 무엇을 했는지 (파일 경로)
- 다음: 이어서 할 일
- 요청: 다른 AI나 선생님에게 필요한 것 (없으면 "없음")
```

## 7. 공통 금지 사항

- 전사본·사진·출처에 없는 사실, 수치, 인명을 지어내지 않는다 → 모르면 칸을 비우거나 `[미확인]`
- 학생 얼굴·실명, 동의 없는 녹음 내용, 식당 영수증·개인 연락처는 보고서에 넣지 않는다
- 원본 녹음(.m4a 등)은 커밋하지 않는다 (`.gitignore`)
- 남의 브랜치에 강제 푸시하지 않는다
