    - herdr 설치, Tailscale·SSH로 휴대폰 원격 접속, 안내서 DOCX 4쪽
    - Claude·Codex 지침 파일 통합, Codex 전역 지침 정리, kordoc MCP 등록(HWP 파싱 확인), CLI-Anything 스킬 설치

### 진단 (해석)
- 강점: 도구 연결·자동화 수준이 높음. 바꾸기 전에 검증하고 백업하는 절차가 몸에 붙어 있음

    - CLI-Anything은 FFmpeg 설치가 남았고 활용 여부는 미정(세션 요약)
- AI 활용 역량 다음 단계는 "설치"보다 "설계": 반복 업무를 AI 파이프라인 하나로 묶어 시간 절감을 재는 것

### 맞춤 조언
1. 다음 주는 새 도구 설치를 쉬고, 이미 깐 도구마다 실제 업무 사례 1개씩 만들기 (예: kordoc으로 HWP 공문 → 요약)
2. herdr·원격 접속 구축 경험을 교원 연수용 "AI 작업 환경 만들기" 1차시 자료로 바꾸기 (센터 업무와 연결)
3. 작업마다 "AI 없이 걸렸을 시간 / 실제 시간"을 노션 로그에 한 칸 추가해 효과를 숫자로 남기기

## AI 활용 방식

### 이번 주 요약 (사실)
- 투입 AI 6개: Claude(총괄·보고서), Codex(자동화·변환), 피클(국내 조사·브리핑·생활 비서), 부이(해외 조사, 시범), 뮤즈·큐(시범)
- 기록량: 노션 로그 피클 14건, 뮤즈 2건, 태그 없음 19건. 커밋 Claude 27, 피클 13, Codex 8, 뮤즈 1
- 피클은 업무 외에 생활 비서 역할도 함: 정부24 주소, 카드 명세서 전달 설정, 광고 메일 1,360건 정리, 결제 영수증 정리
- 협업 장치: 파일 소유권표, AI별 명령서, 업로드 권한 없는 AI의 대리 업로드, 피클의 수치 교차 검증

### 진단 (해석)
- 역할 분담과 교차 검증 구조는 잘 작동함. 특히 "조사(피클) → 작성(Claude) → 대조(피클)" 순환이 효과적임
- 병목 1: 기록이 흩어져 있음
    - Claude 대화 기록 0건
    - PC에서 연 Claude Code 세션 16건은 원문 확인 불가
    - 뮤즈의 11/17~21 작업은 노션 로그에 없음
    - 노션 로그 19건은 어느 AI가 했는지 표시가 없음
- 병목 2: 데일리 브리핑을 피클·뮤즈가 따로 만들어 겹침
- 위험: 공개 저장소에 생활 정보(카드·결제 금액 등)가 섞여 올라갈 수 있음

### 맞춤 조언
1. 모든 AI가 작업 끝에 노션 AI 작업 로그에 [도구명]을 붙여 한 줄 남기기 (Claude 대화도 중요한 것은 한 줄)
2. 데일리 브리핑 담당을 하나로 정하고(피클 추천), 뮤즈는 문제·모범답안 생성에 집중시키기
3. 주간 기록 중 생활 비서 항목은 공개 저장소에 올리지 않기로 규칙 정하기
