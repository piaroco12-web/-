### 실행과 검증

Linux/macOS에서 저장소 루트 기준으로 실행함.

```sh
python -m pip install Pillow pillow-heif
python scripts/organize_photos.py
```

테스트용 JPG·HEIC·PNG 3장으로 실행하여 3장 저장, 오류 0건, 시각 미상 1장을 확인함.

| 번호 | 출력 파일 | 촬영 시각(KST) | JPEG 크기 |
| --- | --- | --- | --- |
| P01 | `1341_채드윅_사진01.jpg` | 11/19 13:41:05 | 960×1920 |
| P02 | `1341-2_채드윅_사진02.jpg` | 11/19 13:41:20 | 1002×1920 |
| P03 | `_시각미상/사진03.jpg` | 미상 | 120×80 |

- JPEG 품질 85, EXIF 방향 반영, HEIC의 UTC 촬영 시각 변환을 확인함. 채드윅·제물포 일정의 시작·종료 분과 일정 밖 분류도 점검함.
- 재실행 결과 0장이 추가되었으며 P번호·설명·보고서 사용 표기를 유지함. 출력 JPEG 한 장이 비었을 때 같은 번호로 복원함. 테스트 원본 3장의 SHA-256이 실행 전후 일치함.
- 저장소에는 현장 자료가 들어올 때 사용할 빈 사진 목록을 올림. 테스트 사진은 임시 폴더에서만 사용함.
